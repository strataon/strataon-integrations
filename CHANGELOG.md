# Changelog

All notable changes to the official STRATAON integration guides and examples are documented in this file.

## [1.0] - 2026-09-19

### Added

- Added the first official STRATAON integration guide.
- Added documentation for integration between the STRATAON miniPLC and the Arteco monitoring platform.
- Added instructions for registering the miniPLC as an external I/O peripheral in Arteco.
- Added configuration for sending miniPLC digital input states to Arteco using Webhooks.
- Added configuration of Webhook variables and Arteco CGI URLs.
- Added instructions for generating and configuring a miniPLC WRITE API token.
- Added configuration for sending commands from Arteco to miniPLC digital outputs using the REST API.

### Documentation

- `arteco/miniplc/manual-miniplc-arteco.pdf`

### Compatibility

- Integration procedures documented for the miniPLC and Arteco interfaces available as of September 2026.
