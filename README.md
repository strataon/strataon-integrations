# STRATAON Integrations

Official integration guides and examples for STRATAON products.

This repository provides technical documentation, configuration guides and examples for integrating STRATAON devices with third-party platforms and systems.

## Available Integrations

### Arteco

Integration between the STRATAON **miniPLC** and the Arteco monitoring platform.

The integration supports bidirectional communication:

- miniPLC sending digital input states to Arteco using Webhooks.
- Arteco sending commands to miniPLC digital outputs using the miniPLC REST API.

Documentation:

- `arteco/miniplc/manual-miniplc-arteco.pdf`
